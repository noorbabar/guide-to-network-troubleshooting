# Network Product Support Guide

a troubleshooting guide for common Microsoft product and network issues.

Built as a reference I can follow when helping customers, and a self service guide anyone can use on their own.


## What actually is this?

a practical support guide for diagnosing and fixing issues I encounter as a Microsoft product advisor. Covers Microsoft 365, Windows, OneDrive, and general network and connectivity problems.

No technical knowledge required to use it. Each issue walks through simple questions and leads to a fix.


## What's Included

- Microsoft 365 installation and activation issues
- Microsoft account sign in problems
- OneDrive sync issues
- Windows startup and update failures
- Network and connectivity troubleshooting
